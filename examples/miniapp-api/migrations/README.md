# 保留的业务迁移历史

此目录完整保留从通用模板拆出前的 14 份历史迁移 SQL 及各自快照，内容未改写；对应旧应用的既有迁移日志表 `drizzle.__drizzle_migrations`。`seed` 与注释同步脚本也保留在本示例。

通用模板现已使用面向新数据库的独立初始迁移，见 [`templates/template-api/migrations`](../../../templates/template-api/migrations/README.md)。两条迁移链不能混用，也不能把新初始迁移应用到已有业务库。

现有开发数据库没有因本次代码拆分而发生迁移或数据变化。继续开发原有小程序业务时，应使用与本目录历史一致的应用代码，并明确配置目标数据库；本示例没有自动继承任何原本地环境文件。

已知历史限制仍然存在：`unified-miniapp-auth` 曾直接删除旧 `client_users`，因此从含有旧业务数据的最早结构升级时并非无损迁移。这里按原样保留历史，不将它描述为已修复；既有数据升级需要单独制定保留方案，不改写已执行历史。
