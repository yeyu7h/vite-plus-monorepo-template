# API 测试契约

角色、用户和 Refine 查询执行器的共同断言集中在这里，由 API 模板和小程序示例各自的 `*.integration.test.ts` 注册。每个应用显式注入自己的路由、中间件、数据库、会话服务和清理函数；共享套件不导入任何应用源码。

该包仅作为应用的开发依赖，不参与生产构建。复制模板创建新应用后，测试入口继续使用工作区中的这份契约。

各入口分别运行同一组场景，保留对应用装配差异的验证。新增应用专属行为的测试应留在应用内；修改共同契约时，应分别运行两个应用的 `test:integration`，并显式提供专用 `TEST_DATABASE_URL` 和 `TEST_REDIS_URL`。清理函数只删除传入前缀所属的数据。
