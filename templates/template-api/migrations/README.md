# 数据库迁移边界

本目录中的 `generic-api-baseline` 是通用 API 模板的新初始迁移，仅创建管理端和通用配置相关表，不创建业务用户、平台身份或 UID 计数器。迁移日志表为 `drizzle.__drizzle_migrations_generic_api`。后续生成的 API 应用在自己的新数据库上沿此迁移链演进。

拆分前的 14 份历史迁移及各自快照，已逐字节保存在 [`examples/miniapp-api/migrations`](../../../examples/miniapp-api/migrations/README.md)。它们包含原有账号表演进及小程序业务实现；原 SQL 和快照未被修改。该示例继续使用原有迁移日志表。

已有数据库不能改用本目录的初始迁移，也不能通过模板的 `push` 清理业务表。保留已有应用代码及其迁移链，或在明确迁移目标与数据保留方案后单独演进。本次拆分没有对开发数据库执行迁移、seed、删表或数据转换。

新应用使用独立的新数据库执行 `migrate` 和 `seed`。如需撤回本次模板拆分，恢复应用源码与其对应的历史目录即可；本次没有为已有数据库生成或执行不可逆清理迁移。
